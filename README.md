# DeskPro para macOS

Distribuição oficial do DeskPro para macOS, compatível com Macs Intel e Apple Silicon.

## Downloads

- A versão mais recente fica disponível em **Releases**.
- O arquivo `.dmg` é usado para a instalação.
- O arquivo `.zip` e `latest-mac.yml` alimentam a atualização automática do aplicativo.

## Publicação

Cada tag `v*` inicia uma compilação limpa em um computador macOS do GitHub Actions e publica automaticamente os arquivos da versão. O canal Windows permanece separado no repositório `deskpro-updates`.

Para distribuição pública sem os avisos de segurança do macOS, configure no repositório os segredos de assinatura e notarização descritos no fluxo de compilação.
